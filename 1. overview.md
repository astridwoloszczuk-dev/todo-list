## todo-list

**Intent:** Family todo manager — browser PWA with per-person tabs, real-time sync, and WhatsApp morning digests.

**Runs on:**
- Browser (PWA) — Supabase real-time, no server needed for the frontend
- James Mac Mini — whatsapp-server (standalone, in `/whatsapp-server/` at CODE root — NOT the copy inside this folder)

**Connects to:**
- Supabase `family-apps` — todos, people, person_blurbs, outbound_messages, birthdays

**Credentials needed:**
- Supabase anon key — embedded in frontend (`app.js`)

**Supabase tables:** `todos`, `people`, `person_blurbs`, `person_digests`, `outbound_messages`, `digest_runs`, `birthdays`, `birthday_reminders`, `birthday_acks`

**Note:** The `whatsapp-server/` subdirectory inside this folder is a duplicate — the live version runs from the standalone `whatsapp-server/` project at CODE root. The copy here should be deleted.
